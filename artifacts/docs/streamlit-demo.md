# Streamlit Demo – Audio Week 5

## Features
1. **Live Mic Record** → classify or transcribe
2. **File Upload** → choose Task 1, 2.1, 2.2
3. **Note Playback** – listen to MIDI predicted by Music Transformer
4. **TTS** – enter text → hear vocoder output

## Run:

```bash
docker compose up -d   # then open :8501
```
